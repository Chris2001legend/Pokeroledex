# PokéroleDex 3.0 | Edizione 100% Android (Senza PC)

Applicazione e database basati sui dati ufficiali di **Pokérole TRPG (Core 3.0)**, **interamente tradotta in italiano** e **funzionante al 100% direttamente dal tuo smartphone Android, senza alcun bisogno del PC!**

---

## 📱 Come Usarla Direttamente su Android (Zero PC)

Non hai bisogno del computer, né di installare server o configurare nulla. Una volta estratta la cartella nella memoria del tuo telefono (es. nella cartella *Download* o *Documenti*):

### 🚀 Avvio Diretto (1 Tocco dal File Manager):
1. Apri l'app **Archivio / Gestione File** (Files di Google, Samsung Archivio, ZArchiver, ecc.) del tuo smartphone.
2. Entra nella cartella estratta **`Android`**.
3. Tocca semplicemente il file:
   👉 **`AVVIA_POKEROLEDEX.html`** (oppure **`index.html`**)
4. L'applicazione si aprirà all'istante in **Google Chrome** o nel browser del tuo smartphone:
   * **Tutti i 1.200 Pokémon** caricati offline
   * **Tutte le 892 Mosse** con formule di danno e precisione in italiano
   * **Tutte le 305 Abilità** e **236 Strumenti**
   * **Tutte le 25 Nature** tradotte
   * **Laboratorio Allenatore & Team** con salvataggio automatico nella memoria del telefono
   * **Lanciatore di Dadi** con vibrazione aptica al tocco!

### 📲 Come Installarla come vera App a Schermo Intero (Icona nella Home):
Una volta aperta l'app nel browser del telefono:
1. Tocca i tre puntini in alto a destra **⋮** su Google Chrome.
2. Tocca **"Aggiungi a schermata Home"** o **"Installa app"**.
3. Verrà creata l'icona Pokérole nella schermata principale del tuo telefono: da quel momento potrai aprirla direttamente con un tocco a schermo intero come qualsiasi normale app Android!

---

## 🛠️ Modalità Alternative per Android

* **Per chi usa Termux su Android:**
  Puoi anche eseguire lo script shell incluso:
  ```bash
  sh avvia_android.sh
  ```
* **Per chi vuole avviare il server da PC e usarlo su più telefoni contemporaneamente:**
  Fai doppio clic su `Pokeroledex_Android.exe` o `AVVIA_POKEROLEDEX_ANDROID.bat`.

---

## 📁 Contenuto della Cartella `Android/`

* **`AVVIA_POKEROLEDEX.html`**: L'esecutivo principale da toccare sul telefono per avviare l'app subito e senza PC.
* **`index.html`**: File principale alternativo per l'apertura immediata.
* **`Back-End/`**: Foglio di stile ottimizzato per touch, logica applicativa tradotta, database offline e manifesto PWA.
* **`DB/`**: Database SQLite relazionale con tutte le tabelle tradotte in italiano.
* **`Storage/`**: Tutti gli sprite ufficiali Pokémon e immagini degli strumenti.
